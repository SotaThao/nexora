## Why

The merchant Voice Knowledge library exposes the required workflows but uses an unstructured card layout and is detached from the Business FAQ field it complements.

## What Changes

- Move the library directly below Business FAQ in Salon Settings.
- Apply the approved Knowledge files layout with capacity, dropzone, document table, guidance, and responsive mobile presentation.
- Preserve every existing API operation, document state, validation, confirmation, and error flow.

## Impact

- **Capability:** `merchant-voice-knowledge-ui`.
- **Frontend:** Salon Settings placement, Voice Knowledge component, interaction tests, and EN/VI localization.
- **API/data model:** unchanged.
