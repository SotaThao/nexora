Customer Tips API Integration Report

Date: 2026-06-07

Scope

This report consolidates the Customer Touch / Customer Tips API integration findings from the new PDF guide, local API docs, Swagger export spec.json, and the live Swagger UI at https://nexora-dev-api.vlinkhub.com/api/.

Key finding: multi-staff tips are blocked unless the anonymous QR flow can obtain businessId. The Merchant endpoint returns it, but that endpoint is authenticated and cannot be used by customers.

Executive Summary

  • Single-staff tips can be integrated now.
  • Skip-tip + review-only can be integrated now.
  • Review submit and Google/Yelp click tracking can be integrated now.
  • Multi-staff tips need businessId in the public flow.

Swagger vs PDF Differences

PaymentMethod enum format

The PDF describes PaymentMethod as an integer enum. Swagger exposes it as a string enum: CashApp, Venmo, Zelle, PayPal, Other, AppleCash.

Recommendation: centralize enum mapping in publicTouchRepository. Prefer Swagger string values unless backend confirms runtime expects integers.

Touch page business payload

PDF and Swagger currently expose only name, logoUrl, and description on public business. This is insufficient for multi-staff tips.
